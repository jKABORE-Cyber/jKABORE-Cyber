## About

I work at the intersection of **offensive application security** and **payment systems**.

I designed and published a **BCEAO/UEMOA-compliant QR payment SDK** (JavaScript/TypeScript, a native port of the Java reference implementation), where I identified and fixed three interoperability gaps between the Java, JS and Python implementations — including a silent data corruption caused by inconsistent ISO-8859-1 handling across languages.

I also carried out a **full mobile security assessment** of a Flutter/Supabase application, from testing through to a prioritised remediation plan.
